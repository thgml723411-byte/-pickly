# MIQ

AI 개인 맞춤 미디어 큐레이션 서비스. 사용자의 취향을 입력받아 AI가 영화/드라마/음악 등을 추천합니다.

## 기술 스택

- React + Vite
- Firebase (Auth, Firestore, Functions, Hosting)
- OpenAI API

## 시작하기

```bash
npm install
cp .env.example .env
npm run dev
```

## Cloud Functions

```bash
cd functions
npm install
firebase emulators:start
```
